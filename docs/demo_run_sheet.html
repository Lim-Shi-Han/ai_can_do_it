APrepare

  1. In two DGX terminals, go to the repo and activate the environment.

    cd /home/ai_zhaoheng/ha_confluence && source .venv/bin/activate

  2. In terminal 1, check that the sign-ins still work. Each should print “Signed in as”.

    python gdrive/gdrive_cli.py check --as Terrance
python gdrive/gdrive_cli.py check --as Zhao

  3. Reset every platform and check Drive. The reset rebuilds the Jira projects, so it takes a few minutes. Wait for “All files are in place.”

    python -m main_workflow.cli reset
python gdrive/demo_drive.py check

  4. Start the server with the local model and leave it running.

    VLLM_BASE_URL=http://127.0.0.1:8500/v1 VLLM_MODEL=qwen-spec-poc python -m main_workflow.web

  5. On your laptop, open the tunnel, then open the chat at http://localhost:8090 and the console at http://localhost:8090/console side by side.

    ssh -L 8090:localhost:8090 <dgx-host>

  6. In the console, wait for “Slack bot connected” under Activity, then press Sync now and Refresh. The chat footer should say “Slack synced” with no asterisk.

  1. On your laptop, open Slack at https://companya-civ9707.slack.com signed in as Zhao, on one half of the screen. Put an SSH terminal to the DGX on the other half.

  2. Clear the demo channels. This deletes every message and keeps the members. If the web server is not running, also rebuild the search index so the chat forgets the deleted messages.

CAfter the run

Reset for the next rehearsal

Stop the server with Ctrl+C, then reset. With the server stopped, the reset also clears the audit trail and search index.

python -m main_workflow.cli reset

If something goes wrong

An upload is refused
Terrance is not shared as Editor yet (row 5), or a sign-in expired. Check with python gdrive/gdrive_cli.py check --as <Name>.
A sign-in has expired
Run python gdrive/gdrive_cli.py login <Name> with that account.
Ticket numbers do not match
A ticket was created out of order. Reset and start again.
Timing
Answers take 4–8 seconds, ticket drafts about 10, uploads and the report 5–10 each.
